**EvoKasir** adalah sistem _Point of Sale_ (POS) modern yang dibangun dengan **Laravel 11**. Dirancang untuk memberikan solusi manajemen kasir yang efisien, sistem ini mendukung fungsionalitas multi-mitra, laporan pendapatan terperinci, dan dilengkapi dengan API yang aman menggunakan Laravel Sanctum.

## ✅ Fitur Utama

-   **Manajemen Multi-Mitra**: Mengelola beberapa cabang atau bisnis dari satu platform.
-   **Manajemen Produk**: CRUD (Create, Read, Update, Delete) untuk produk, termasuk kategori dan harga.
-   **Sistem Pemesanan**: Proses transaksi pesanan yang intuitif dengan integrasi ke meja.
-   **Dashboard Analitik**: Visualisasi data pendapatan (harian, mingguan, bulanan, tahunan) dan produk terlaris menggunakan **Chart.js**.
-   **Laporan Historis**: Laporan pendapatan per bulan dan per tahun dengan rincian produk dalam format accordion interaktif.
-   **Otentikasi API**: Endpoint API yang aman untuk aplikasi eksternal (misal: aplikasi mobile) menggunakan **Laravel Sanctum**.
-   **Notifikasi Real-time**: Notifikasi suara untuk pesanan baru yang masuk.
-   **Manajemen Meja**: Fitur untuk membuat dan mengelola status meja (tersedia, terisi, dll.) dengan pembuatan QR code untuk setiap meja.

---

## 🛠️ Tumpukan Teknologi

-   **Backend**: Laravel 11
-   **Frontend**: Blade, Tailwind CSS, Alpine.js
-   **Database**: MySQL / MariaDB
-   **Lainnya**: Chart.js untuk grafik, DomPDF untuk generasi PDF, Laravel Eloquent & Query Builder.
